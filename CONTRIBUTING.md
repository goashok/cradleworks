# Contributing

Cradleworks is open source, but it is not open to outside contributions. You are free to read,
use, change and share the code under the [Apache License 2.0](LICENSE). Pull requests from
outside the project are closed automatically, without review.

That isn't a judgment of your work. It keeps the project's ownership simple while it is young.
That may change later; if it does, this file will say so.

## What is welcome

- **Bug reports.** Open an issue with what you ran, what you expected and what happened, and the
  factory version (`factory --version`). Logs help; take out any keys or tokens first.
- **Ideas and feature requests.** Open an issue describing the problem you want solved. Ideas
  that fit the roadmap ([docs/roadmap.md](docs/roadmap.md)) may be built into a later version.
- **Questions.** Open an issue if the documentation doesn't answer one.

Please describe a fix in words rather than posting code: code in an issue can't be used, so any
fix is written from scratch.

## Security problems

Don't report a security problem in a public issue. Use GitHub's private reporting instead: the
repository's **Security** tab, then **Report a vulnerability**.

## Your own copy

The licence lets you fork Cradleworks and change it however you like. A fork is yours to run; it
just won't be merged back here.
